# ویدیوی آموزشی NavSim — از سنسور تا پاسخ ناوبری

ویدیوی انیمیشنی گرافیکی با روایت **فارسی** که کل فرایند شبیه‌ساز ناوبری را
آموزش می‌دهد: داده از کجا می‌آید، به کجا می‌رود، چرا، و پارامترها باید چه مقدار باشند.

- **ویدیوی کامل (۱۶ صحنه، ~۲۴ دقیقه، 1080p):** `video/NavSim_educational_video.mp4`
- نسخهٔ کوتاه‌تر (۱۰ صحنهٔ انتخابی): `video/NavSim_part1_10scenes.mp4`

## ساخت مجدد ویدیو (اختیاری)

کد انیمیشن با Python (PIL + HarfBuzz برای شکل‌دهی درست فارسی + av برای کدک)
ساخته شده و کاملاً دیتادریو نیست: متن هر صحنه در `scenes/sXX.py` و زمان‌بندی
انیمیشن‌ها بر اساس مدت فایل صوتی `audio/Sxx.mp3` تنظیم می‌شود.

```bash
pip install numpy Pillow fonttools uharfbuzz av imageio-ffmpeg
cd educational_video
python render_all.py          # رندر همهٔ صحنه‌ها + ترکیب نهایی
```

فونت‌ها در `fonts/` (Vazirmatn برای فارسی + DejaVu برای فرمول‌ها/یونانی).
متن کامل نریشن هر صحنه در `docs/narration_script.md`.
