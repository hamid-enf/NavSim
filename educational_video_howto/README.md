# ویدیوی دوم: راهنمای عملی کار با شبیه‌ساز در متلب

ویدیوی انیمیشنی گرافیکی با روایت **فارسی** برای تسلط روی خودِ ابزار:
هر تب، هر پارامتر (مقدار پیش‌فرض + معنی)، پروتکل تست استاندارد، خواندن نمودارها،
دادهٔ فلو، آزمایش‌ها، لاگینگ، runAllTests، و چک‌لیست متخصص.

- **ویدیو (۱۸ صحنه، ~۲۷ دقیقه، 1080p):** `video/NavSim_howto_matlab.mp4`
- پیش‌نیاز: ویدیوی اول (`../educational_video/`) برای فهم فرایند و دیتا‌فلو

## فهرست صحنه‌ها

| # | صحنه | محتوا |
|---|------|-------|
| H01 | مقدمه و هدف | از کاربرِ کلیک‌زن تا اپراتورِ مسلط |
| H02 | آناتومی پنجره | ستون چپ (تب‌ها/Transport/وضعیت) و ستون راست (نمودارها/3D/Data Flow) |
| H03 | تب Simulation | dt، مدت، seed (تکرارپذیری)، realtime/fast، variable dt |
| H04 | تب Trajectory | ۹ مسیر + UserDefined؛ انتخاب مسیر = تعیینِ قابل‌مشاهده‌شدن |
| H05 | تب IMU | بایاس/نویز/SF/کج‌بودن/دینامیک بایاس/اثرات فیزیکی |
| H06 | تب GNSS | نرخ، σ افقی/عمودی، قطعی، پرت، تأخیر، نویز همبسته |
| H07 | تب Baro | کمک کانال عمودی (تونل) |
| H08 | تب INS و Align | مرجع، flat/wgs84، جملات تک‌تک، تراز static/moving |
| H09 | تب Fusion | mode، Q، P صفر، qScale/rScale، NIS، OOSM، ZUPT |
| H10 | تب Errors | همهٔ کلیدها در یک صفحه + پروتکل «یک منبع در هر بار» |
| H11 | Transport | دکمه‌ها + پروتکل تست استاندارد ۵ مرحله‌ای |
| H12 | نمودارها | کد رنگ، هر تب، سؤال‌های حکم‌کننده |
| H13 | Data Flow | مقادیر زندهٔ هر مرحله + پنل آموزشی |
| H14 | Experiments | ۱۰ آزمایش + Apply to Config / Run Headless & Compare + اعداد مرجع |
| H15 | Logs | ستون‌های لاگ، flag‌ها، Load/Replay |
| H16 | runAllTests | ۱۴ تست headless + آینهٔ پایتونی |
| H17 | سناریوهای یادگیری | ۵ سناریو + قانون طلایی |
| H18 | چک‌لیست متخصص | ۳ سؤال پیش از تست + بعد از تست + گسترش ابزار |
