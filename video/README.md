# ویدیوی آموزشی NavSim (فارسی، 4K)

کلیپ آموزشی انیمیشنی و گرافیکی پروژهٔ NavSim به زبان فارسی؛ جریان کامل داده
(`Trajectory → Truth → IMU → Calibration → INS → Prediction → Fusion → Output`)
را مرحله‌به‌مرحله توضیح می‌دهد.

- **فایل نهایی:** `NavSim_educational_4K.mp4` — به‌دلیل حجم ~۱۹۸ مگابایتی در خودِ گیت قرار
  نمی‌گیرد؛ از طریق **GitHub Release** (برچسب `video-1.0.0`) یا بازتولید از سورس (پایین) در دسترس است.
- **رزولوشن:** 3840×2160 (4K UHD) — H.264 / yuv420p · **مدت:** ~۱۵:۵۱ · **صدا:** گویش فارسی

## محتوای این پوشه

| فایل | توضیح |
|---|---|
| `narration.py` | متن فارسی گویندگی ۹ صحنه |
| `scenes.py` | تعریف ۹ صحنهٔ گرافیکی (نمودارها، دیاگرام جریان داده، فرمول‌ها) |
| `lib.py` | کتابخانهٔ رندر (متن فارسی RTL، فرمول‌های LaTeX، شکل‌ها، چارت‌ها) |
| `gen_data.py` | تولید دادهٔ واقعی چارت‌ها از آینهٔ پایتونی موتور (`../tools/navsim_mirror.py`) |
| `build.py` | مونتاژ صدا + رندر فریم‌ها + انکود نهایی (نیازمند `imageio-ffmpeg`) |
| `serve.py` | سرور دانلود ساده برای فایل نهایی و فایل‌های همراه |
| `data/*.npz` | دادهٔ عددی واقعی شبیه‌سازی (dropout، تخمین بایاس ژیرو، drift و…) |
| `fonts/` | فونت‌های فارسی (Vazir و…) + DejaVu |
| `audio/*.mp3` | کلیپ‌های صوتی گویندگی هر صحنه |

## ۹ صحنهٔ ویدیو

1. مقدمه و نمای کلی جریان داده + شاخهٔ GNSS
2. مسیر و حالت واقعی (دستگاه NED، ۹ مسیر، `ω_b` و `f_b`)
3. مدل خطای IMU (بایاس، نویز ARW/VRW، مقیاس، ناهم‌راستایی، g-sensitivity، اشباع، کوانتیزاسیون)
4. کالیبراسیون + مکانیزاسیون INS (کواترنیون، flat/WGS84، ریشهٔ دریفت `½·b·t²`)
5. مدل GNSS (نویز H/V، نرخ 1 Hz، Dropout، Outlier، تأخیر، خطای گاوس-مارکوف)
6. فیلتر تلفیق ۱ — مدل خطای ۱۵حالته و پیش‌بینی (Q، کوواریانس)
7. فیلتر تلفیق ۲ — به‌روزرسانی، گیتینگ NIS، فیدبک حلقه‌بسته، مشاهده‌پذیری
8. ایدینگ کمکی (Baro/ZUPT) + خروجی و تحلیل خطا با اعداد واقعی
9. پارامترهای کلیدی و جمع‌بندی

اعداد داخل چارت‌ها واقعی‌اند و از آینهٔ عددی پایتونی خود پروژه (`tools/navsim_mirror.py`)
با `seed=1` تولید شده‌اند (مثلاً قطع ۳۰ ثانیه‌ای GNSS: خطای INS ≈ ۱۲۳۵ متر در برابر
خطای Fused ≈ ۳۱ متر و بازگشت ≈ ۱٫۹ متر).

## بازتولید

```bash
python -m venv .venv && source .venv/bin/activate
python -m pip install -r ../requirements-dev.txt
python -m pip install Pillow numpy matplotlib arabic-reshaper python-bidi imageio-ffmpeg

python gen_data.py     # دادهٔ واقعی چارت‌ها (از navsim_mirror.py)
# گویندگی هر صحنه را با TTS در audio/clip_00.mp3 ... clip_08.mp3 قرار دهید
python build.py        # ساخت audio_track.wav + رندر و انکود 4K (نیازمند ffmpeg)
```

رندر 4K روی سخت‌افزار ۲ هسته‌ای حدود ۵۰ دقیقه زمان می‌برد (تک‌پروسه + انکودر همزمان).
